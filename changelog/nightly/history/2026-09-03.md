A focused nightly today, centered on a single interface fix: the streaming chat surface now measures the live composer instead of assuming a fixed height, so replies and the cooking indicator no longer hide behind the input bar on mobile web.

## 11:17 AM — Streaming replies stay above the mobile composer

The chat surface now derives its bottom clearance from the actual input bar height, fixing cases where the streaming indicator and message tail were obscured by the composer — especially when AURA Council expanded the input into a taller multi-slot footer.

- Replaced the static ~212px bottom padding with a live --chat-input-clearance variable driven by the measured composer, so scroll reserve and the pinned cooking indicator track the real input height on mobile web. (`6450deb`)
- Added coverage for the compact mobile input bar to lock in the computed indicator offset and clearance values, guarding against regressions when the composer changes size. (`6450deb`)
