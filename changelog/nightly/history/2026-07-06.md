# Reliable fresh-session handoff in the chat app

- Date: `2026-07-06`
- Channel: `nightly`
- Version: `0.1.0-nightly.731.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.731.1

A focused nightly with a single, targeted fix to how the chat app opens brand-new sessions, making the transition from a fresh canvas to a live conversation behave predictably.

## 3:10 AM — Fresh chat sessions bind cleanly on first send

The chat app now consistently treats a fresh route as a pending new session and arms the next message to start that session, preventing the first send from attaching to the wrong context.

- Fresh-canvas state is always active when no session is selected, so opening a new chat reliably prepares a new session instead of depending on whether a fresh chat id had been generated yet. (`378f600`)
- Introduced a per-conversation freshCanvasKey passed through useChatAppChat and useStandaloneAgentChat, so each new fresh chat re-arms the next send as a new session rather than reusing prior arming. (`378f600`)

## Highlights

- Fresh chat sessions bind correctly on the first send
- Fresh-canvas state now keyed per new conversation
