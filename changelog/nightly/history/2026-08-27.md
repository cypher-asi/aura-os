# Global command palette lands on Cmd/Ctrl+K

- Date: `2026-08-27`
- Channel: `nightly`
- Version: `0.1.0-nightly.807.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.807.1

Today's nightly is focused on a single, meaningful addition: a global command palette for the Aura shell that makes chats, apps, projects, agents, and menu actions reachable from one keystroke. It ships alongside an internal audit documenting how Aura's discovery surface should evolve from here.

## 7:23 AM — Global command palette on Cmd/Ctrl+K

Aura Shell now exposes a single palette that searches recent chats, apps, projects, agents, and menu actions, with a dedicated action-only mode.

- Added a global command palette to Aura Shell, opened via Cmd/Ctrl+K, that searches across cached chats, apps, projects, agents, and registered menu actions from one input. (`3cdf448`)
- Wired the palette into the existing menu registry and UI modal store so it reuses canonical routes and action handlers instead of introducing a parallel navigation path, and skips disabled actions during keyboard navigation. (`3cdf448`)
- Introduced a `>` prefix to scope results to actions only, making it fast to run menu commands without wading through content matches. (`3cdf448`)
- Published a T3 code reference audit in the docs that frames this palette as the first slice of a broader discovery effort, with server-backed message and file-content search called out as the next increments. (`3cdf448`)

## Highlights

- Global Cmd/Ctrl+K command palette across the Aura shell
- Unified search over chats, apps, projects, agents, and menu actions
- Published T3 code reference audit shaping upcoming discovery work
