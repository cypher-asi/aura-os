# Notion integration rejects unauthorized requests

- Date: `2026-07-02`
- Channel: `nightly`
- Version: `0.1.0-nightly.721.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.721.1

A focused nightly centered on tightening how Aura's Notion integration handles authentication, with matching test coverage to lock the behavior in.

## 2:17 AM — Notion provider enforces bearer token auth

The Notion integration runtime and its mock server now validate the Authorization header and return a clear 401 when credentials are missing or wrong.

- Notion provider requests without a valid bearer token are now rejected with a 401 and a descriptive error instead of silently returning fixture data, hardening the integration against misconfigured or unauthenticated callers. (`c5d2e62`)
- The provider mock used in integration tests was reworked to inspect the Authorization header on every Notion route (search, pages, markdown, blocks, databases, data sources) so the new auth path is verified end-to-end. (`c5d2e62`)
