# Claude Opus 5 lands and safe workspaces isolate parallel agent turns

- Date: `2026-07-28`
- Channel: `nightly`
- Version: `0.1.0-nightly.777.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.777.1

Today's nightly brings two substantial changes: Aura picks up Claude Opus 5 as its new frontier model across chat, pricing, and bug-report triage, and a new opt-in "safe workspace" mode gives parallel agent sessions their own Git worktree with checkpoint and apply-back semantics so concurrent editing turns no longer race on shared project files.

## 4:26 AM — Claude Opus 5 becomes the new frontier model

Opus 5 is now selectable across chat, wired into pricing and reasoning-effort tiers, and promoted to Aura's default frontier model for triage and defaults.

- Added Claude Opus 5 to the Anthropic chat model list with the full low/medium/high/xhigh/max reasoning-effort ladder, a 1M context window, a 5× credit multiplier, and a default 'high' effort tier. (`51338b7`)
- Registered Opus 5 pricing ($5 in / $25 out per MTok, with $6.25 cache write and $0.50 cache read) in both the runtime pricing table and the benchmark pricing script, and normalized the `aura-claude-opus-5` id to the provider's `claude-opus-5` key. (`51338b7`)
- Promoted Opus 5 to `LATEST_FRONTIER_MODEL` and switched the server-side bug report triage summary from Opus 4.8 to Opus 5. (`51338b7`)

## 5:48 PM — Safe workspaces for parallel agent sessions

A new opt-in execution mode gives each storage session its own Git worktree with pre-turn filesystem checkpoints, preview, exact restore, and conflict-checked apply-back, so concurrent editing turns on the same project stop racing on shared files.

- Introduced a `safe_workspace` flag on chat requests that spins up a detached Git worktree per storage session, points the harness at it, and snapshots non-ignored files before each turn — with checkpoint preview, exact restore, and conflict-checked apply-back APIs implemented in the new `handlers/agents/safe_workspace.rs` module (~1.3k lines) and exposed on the agents router. (`9919d5a`)
- Added a `SafeWorkspaceBar` to the desktop and mobile agent chat panels so users can see and control the isolated workspace state directly from the chat surface, backed by new agent API helpers and streaming hook plumbing. (`9919d5a`)
- Documented the new isolation model in `PARALLEL_SESSIONS.md`, clarifying that safe workspaces are opt-in, require a persisted session and a linked local Git repo, and that the shared PTY and remote agents keep the existing execution model. (`9919d5a`)
- Hardened macOS native notifications to detect whether the process is running from a real `.app` bundle and skip authorization (and refuse to post) for unbundled dev builds instead of erroring. (`9919d5a`)

## Highlights

- Claude Opus 5 available as the new frontier model
- Opt-in safe workspaces isolate concurrent agent edits
- macOS notifications no longer error on unbundled builds
