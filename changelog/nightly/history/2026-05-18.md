# Quieter auth logs by relocating the signup credit grant

- Date: `2026-05-18`
- Channel: `nightly`
- Version: `0.1.0-nightly.538.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.538.1

A small but focused server-side cleanup today: the signup credit grant no longer fires on every session restore, cutting noisy background work and log spam from the auth path. Desktop builds shipped for macOS (Apple Silicon and Intel), Windows, and Linux on the nightly channel.

## 2:20 AM — Signup credit grant removed from session restore path

The best-effort welcome and daily credit grant no longer runs on every get_session call, eliminating a recurring background task and the log noise it generated.

- Dropped the spawned grant_signup_credits call from get_session on the Aura server, so session restores no longer trigger a redundant idempotent credit grant on every request and stop flooding the auth logs. (`1c70f03`)

## Highlights

- Signup credit grant removed from get_session hot path
- Less log spam from repeated session restores
- Nightly desktop artifacts shipped for Mac, Windows, and Linux
