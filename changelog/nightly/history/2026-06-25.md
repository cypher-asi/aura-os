# Stream watchdog softening, model catalog refresh, and sidebar context menus return

- Date: `2026-06-25`
- Channel: `nightly`
- Version: `0.1.0-nightly.709.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.709.1

A focused nightly across chat reliability and the model picker: the stream watchdog no longer kills long extended-thinking turns you've already been billed for, the GPT-5.4 family stops 400-ing on an unsupported reasoning tier, and three new Fireworks-hosted models join the catalog. The projects sidebar also gets its right-click menu and F2 rename back, and the server starts emitting billing-enriched usage signals for completed turns.

## 3:21 AM — Projects sidebar right-click and F2 rename work again

A missing DOM marker on the migrated LeftMenuTree was silently breaking every context-menu action in the projects sidebar.

- Restored Remove from Project, Rename, Add Agent, Delete Project, and F2-to-rename in the projects sidebar by emitting the `data-list-item` marker that `useExplorerMenus` uses to resolve the clicked row — also re-enabling the delete path for archived agents. (`e019773`)

## 11:44 PM — Per-turn usage-signal analytics with billing enrichment

The server now classifies completed chat turns and ships an enriched signal to Mixpanel, backed by a new `aura-os-usage-signals` crate.

- Introduced a pure usage-signal classifier (new `aura-os-usage-signals` crate) and wired server-side emission for completed chat turns, persisted as `turn_usage_signal` and sent to Mixpanel as `agent_turn_classified`. (`e2cc022`)
- Enriched each signal with z-billing context — account age, funding and grant-usage buckets, lifetime purchased/granted/used cents, and balance — plus per-turn shape (plan mode, council, cross-agent, attachments, project binding source). (`e2cc022`)

## 1:54 PM — GPT-5.4 reasoning tiers fixed and three Fireworks models added

The model picker stops offering an effort tier the GPT-5.4 API rejects, and Kimi K2.7 Code, GLM 5.2, and Qwen3.7 Plus join the catalog.

- Removed the unsupported `minimal` reasoning effort from GPT-5.4 / -mini / -nano (their native set is none/low/medium/high/xhigh) and flipped nano's default from `minimal` to `low`, ending the 400s that had broken every nano call; persisted `minimal` self-heals via existing validation. (`aa57d78`)
- Added Kimi K2.7 Code (256K), GLM 5.2 (1M), and Qwen3.7 Plus (256K) as Fireworks-hosted chat models, including catalog entries, legacy-id aliases, display pricing, and the benchmark-pricing mirror. (`1fe8f07`)

## 5:16 AM — Model picker no longer stacks overlapping hover flyouts

Fixed a scroll-vs-coordinator race that let closed model rows resurrect their flyout, producing overlapping panels in the picker.

- Tracked open/closed intent in a synchronous ref so a stale scroll-reflow on an already-closed model row bails instead of re-opening its flyout, while still letting genuinely-open flyouts reposition live; regression tests pin the single-open invariant and the close-then-scroll race. (`9209a18`)

## 10:11 AM — Stuck-stream watchdog stops killing live extended-thinking turns

The destructive 60s client-side auto-abort was cancelling long but still-alive turns that the upstream then billed; the hard cap moves to 5 minutes of truly dead silence.

- Moved the destructive auto-abort from 60s of wire silence to a 5-minute absolute safety cap (`ABSOLUTE_TIMEOUT_MS = 300_000`), so long extended-thinking turns are no longer cancelled — and no longer billed-but-shown-as-failed — and the 90s SSE idle reattach can recover genuine socket drops first. (`f33920b`)
- Kept the non-destructive 30s "taking longer than usual" pill (Stop / Retry / Report) unchanged, and added a regression test pinning that no auto-abort fires at the old 60s mark — only at the absolute cap. (`f33920b`)

## Highlights

- Stuck-stream auto-abort softened from 60s to a 5-minute safety cap
- Kimi K2.7 Code, GLM 5.2, and Qwen3.7 Plus added
- Right-click and F2 rename restored in the projects sidebar
- Usage-signal analytics with billing enrichment now emitted per turn
