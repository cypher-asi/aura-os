# Stable desktop builds get their billing credentials back

- Date: `2026-05-16`
- Channel: `nightly`
- Version: `0.1.0-nightly.533.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.533.1

A small but high-impact CI fix today: stable desktop builds were shipping without a billing API key, silently breaking signup and recurring credit grants. One workflow change restores credits end-to-end for desktop users.

## 9:25 AM — Desktop credit grants restored on stable channel

The stable release workflow was missing the billing API key secret, so desktop builds compiled with an empty key and silently skipped credit grants on login. The secret is now wired into release-stable.yml to match the nightly pipeline.

- Stable desktop builds now receive Z_BILLING_API_KEY at build time, matching the nightly workflow and fixing parity between the two release pipelines. (`71cb9e6`)
- Restores welcome credits, daily credits, and pro top-ups for desktop users on Mac, Windows, and Linux — grant_signup_credits was silently no-opping on every desktop login before this fix. (`71cb9e6`)

## Highlights

- Stable desktop builds now ship with billing credentials wired up
- Welcome, daily, and pro top-up credits restored on desktop login
