# Google Gmail and Calendar arrive as first-class org integrations

- Date: `2026-06-06`
- Channel: `nightly`
- Version: `0.1.0-nightly.629.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.629.1

Today's nightly is focused on a single, sizable shipped capability: connecting Aura to Google. Users can now link Gmail and Calendar through the org integrations surface, backed by a new trusted-runtime path on the server and an overhauled integration editor in the interface.

## 2:54 PM — Google Gmail and Calendar integration

Aura can now connect to a user's Google account and expose Gmail and Calendar as org tools, with end-to-end support across the server, integrations crate, and settings UI.

- Users can connect Gmail and Calendar from Org Settings → Integrations via a new Google OAuth flow proxied through aura-integrations, with the required AURA_INTEGRATIONS_URL wiring documented in the README and .env.example. (`0f3fce7`)
- A new trusted-runtime module and Google trusted methods (~340 lines in trusted_methods/google.rs plus helpers) back the Gmail and Calendar tool calls server-side, with integration_actions and provider mock tests covering the path. (`0f3fce7`)
- Org tool dispatch now carries the authenticated user's identity into provider calls, tightening ownership so Google actions execute against the connecting user rather than the org generically — every provider handler (Apify, Brave, Buffer, Freepik, GitHub, Linear, Mailchimp, Metricool, Notion, Resend, Slack) was updated to the new signature. (`0f3fce7`)
- The Integration Editor and Org Settings Integrations panel were substantially reworked (~300 lines in IntegrationEditor, ~170 in OrgSettingsIntegrations) and covered by a new google-integration-ui Playwright spec, giving the Google connect/disconnect experience a dedicated UI surface. (`0f3fce7`)

## Highlights

- Gmail and Calendar connectable via Google OAuth
- New trusted-runtime path for Google tool calls
- Integration editor reworked for per-user ownership
