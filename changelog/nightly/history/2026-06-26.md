# Changelog access lands directly inside Settings

- Date: `2026-06-26`
- Channel: `nightly`
- Version: `0.1.0-nightly.711.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.711.1

Today's nightly threads a single feature end-to-end: a Change Log entry point in Settings that opens the live, in-app changelog instead of bouncing users out to the web. Follow-up polish trims the embedded view to fit its in-app context.

## 4:40 AM — Change Log shortcut in Settings → Updates

The Updates section of organization settings now surfaces a direct entry point to the product changelog.

- Added a Change Log link to the Updates area of Org Settings so users can jump to release notes without hunting through menus. (`d0791d1`)

## 1:26 AM — Settings Change Log now opens the in-app modal

The new Settings link was rewired to the live in-app changelog and trimmed of out-of-app affordances so desktop and web users stay inside Aura.

- Settings → Change Log now opens the same in-app ChangelogModal used by the Help menu instead of linking out to aura.ai/changelog, which on desktop or web could reload the app or land users on a logged-out page. (`2a230e7`)
- When the changelog renders inside the in-app modal, the header's Download and GitHub links are hidden and the version is shown as plain text rather than a click-to-download button — in-app users update via Settings, while the public /changelog marketing page keeps its full header. (`7e7e6f7`)

## Highlights

- Change Log shortcut added to Settings → Updates
- In-app changelog modal replaces external web link
- Embedded changelog hides Download and GitHub affordances
