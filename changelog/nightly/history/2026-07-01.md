# Claude Sonnet 5 lands as Aura's new default

- Date: `2026-07-01`
- Channel: `nightly`
- Version: `0.1.0-nightly.718.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.718.1

Today's nightly brings Anthropic's Sonnet 5 into Aura — first as a new option in the model picker, then promoted to the default chat model. Everyday conversations now run on a 1M-token context model out of the box.

## 1:38 AM — Claude Sonnet 5 joins the catalog and becomes the default

Sonnet 5 is available in the model picker and now powers Aura's default chat experience, with a 1M-token context window at the same Sonnet-tier pricing.

- Added Claude Sonnet 5 to the model picker as a featured Anthropic option, with a 1M-token context window, Anthropic effort levels, and Sonnet-tier pricing ($3/$15 per M tokens plus cache rates) wired through both model-pricing.ts and the benchmark pricing table. (`7b0b131`)
- Promoted Sonnet 5 to Aura's default chat model by pointing DEFAULT_CHAT_MODEL_ID at aura-claude-sonnet-5 and moving the "default everyday model" description onto it, so new sessions and fallbacks land on Sonnet 5 automatically. (`89c4e68`)
- Registered legacy and raw Claude Sonnet 5 identifiers as aliases so existing persisted model preferences resolve cleanly to the new entry instead of falling back silently. (`7b0b131`)

## Highlights

- Claude Sonnet 5 added to the model catalog
- Sonnet 5 is now the default chat model
- 1M-token context window by default
