# Android mobile hits release readiness

- Date: `2026-09-15`
- Channel: `nightly`
- Version: `0.1.0-nightly.837.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.837.1

Today's nightly is a focused mobile push: a single large change rounds out the Android build so it can ship. It brings SPA-aware back navigation, cleaner project and chat flows on small screens, and CI adjustments to keep the Android release pipeline green.

## 1:13 PM — Android back button, mobile navigation, and release pipeline land together

A single PR closes the remaining gaps blocking an Android release: native back-navigation behavior, mobile shell polish, capability-aware agent setup, and greener Android CI runs.

- Android's hardware back button now cooperates with the in-app React Router history via a new OnBackPressedCallback in MainActivity, popping SPA routes before falling through to the default activity back behavior so users no longer get bounced out of the app on same-document navigations. (`ad4d78f`)
- Mobile shell gains a persistent Chat entry point, exposes project creation from navigation, and lets users create tasks directly from a project, tightening the core mobile flows across MobileShell, ProjectNavigationDrawer, and the Project Tasks/Work views. (`ad4d78f`)
- Hosted agent setup on mobile is now capability-aware through use-aura-capabilities and the refreshed ProjectAgentSetupView, and long technical chat errors collapse into a readable mobile-friendly summary in MessageBubble. (`ad4d78f`)
- Android CI is realigned with current toolchains: the android-mobile and release-mobile-nightly workflows pin setup-android to install explicit SDK packages, working around the removal of the legacy `tools` package in command-line tools v20 that was breaking nightly builds. (`ad4d78f`)

## Highlights

- Android in-app back button now follows SPA history
- Persistent Chat entry point and project task creation on mobile
- Capability-aware hosted agent setup on mobile
- Android SDK setup fixed for command-line tools v20
