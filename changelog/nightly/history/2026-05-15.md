# Public mode launches and cross-agent chat becomes legible

- Date: `2026-05-15`
- Channel: `nightly`
- Version: `0.1.0-nightly.532.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.532.1

A big day for Aura: anonymous visitors can now try Code, Plan, Image, Video, and 3D directly from a new logged-out shell, cross-agent messages finally route and render correctly end-to-end, and a long tail of fixes tightened the Windows terminal, embedded browser error pages, image-generation ETAs, and the macOS/Windows release pipelines.

## 2:48 PM — Windows terminal, themed browser errors, and chat bubble polish

A dense afternoon of UI and platform fixes spanning the in-app terminal on Windows, the embedded browser's error handling, and a refresh of chat bubble styling and copy behavior.

- Rewrote the Windows in-app terminal: PTY spawn now waits for xterm.js to measure its container, PSReadLine is removed on launch, and a Ctrl+L safety net wipes scrollback locally — eliminating the cursor-jumping, overlapping-text, and broken `clear`/`cls` bugs on PowerShell. (`2d71645`, `ad104f7`, `60ce967`)
- The embedded browser now paints Aura's themed error overlay for HTTP 4xx/5xx as well as network failures, and the overlay survives Chromium's native error-page commit, address-bar reloads, and the initial-navigation race that previously hid it until refresh. (`c904d22`, `2a39a37`, `4796ed5`, `1a75fd4`)
- Chat user bubbles now follow the active accent (with per-theme contrast), got rounder corners and a shorter footprint, and gained a hover-revealed copy button; assistant copy and spec/large-text blocks now preserve markdown source on the clipboard while still pasting as formatted text into rich editors. (`51fa6e5`, `2cc4aab`, `601f4df`)
- Floating popovers across the app now share the panel background instead of looking like a lighter elevated shelf, terminal selection follows the accent color, and the Context popover hydrates its per-bucket breakdown immediately on chat mount instead of waiting for the next turn. (`5085111`, `82d1efe`, `a35aeea`)
- Sidekick terminals now show a browser-style tab strip with always-visible session tabs, an inline `+`, and per-session close — backed by a shared `InstanceTabs` primitive used by both browser and terminal panes; the env-overlay also refreshes the Workspace Folder row after project/agent saves instead of waiting for a manual reload. (`d7edffb`, `5397b7c`)
- Hardened the macOS parity gate so it stops misidentifying Homebrew's rustup-init shim as `rustc 1.29.0`, walking PATH and validating the version banner before accepting a candidate. (`16f3ae7`)

## 5:43 PM — Anthropic 529 retries in the changelog generator

Release tooling becomes resilient to upstream overload errors.

- The daily changelog generator now retries Anthropic Messages API calls with exponential backoff, full jitter, and retry-after handling, so a single `overloaded_error` no longer fails the Publish/Reconcile Release Changelog job. (`66cb93e`)

## 5:46 PM — Faster, quieter Windows desktop updates

The desktop updater stops flashing a console window on Windows and surfaces new releases much sooner.

- Fixed a visible console flash on every Windows update handoff by dropping `DETACHED_PROCESS` so `CREATE_NO_WINDOW` is honored and child apps inherit the hidden console. (`22694c1`)
- The titlebar Update pill and Settings Update control now re-check for releases on window focus / tab visibility (with a 60s cooldown), and the desktop poll interval drops from 30 minutes to 5 minutes, so returning to Aura after a release ships surfaces the pill almost instantly. (`0f74153`)

## 6:16 PM — Taming the Homebrew rustup shim on macOS CI

A focused thread of CI fixes that finally pinned the right Rust toolchain on macos-latest runners and stopped a parallel sccache install race.

- Replaced the seven `dtolnay/rust-toolchain` usages across the desktop-validate, release-nightly, and release-stable workflows with a new composite `setup-rust-toolchain` action that probes `RUSTUP_HOME/toolchains/<tc>/bin` directly and prepends it to `$GITHUB_PATH`, so `cargo` / `rustc` / `clippy-driver` on macos-latest stop resolving to Homebrew's broken rustup-init shim. (`43776f8`, `781ab0f`)
- The new setup action also scrubs stale `lib/rustlib/src` trees and exports `RUSTUP_AUTO_INSTALL=0` to prevent parallel sccache rustc invocations from racing rustup into a `rust-src` reinstall conflict mid-build. (`94af218`)

## 2:32 AM — Logged-out public mode, cross-agent chat, and image-generation ETAs

The day's largest batch: a brand-new anonymous web shell with rate-limited Code/Plan/Image/Video/3D, the final phases of the cross-agent messaging fix, and a series of fixes to image generation streaming and its on-screen countdown.

- Shipped an end-to-end logged-out public mode: a new slim shell at `/` with sessions panel, marketing footer, and the promoted `features/chat-ui` input bar lets anonymous web visitors run up to 3 turns of Code, Plan, Image, Video, or 3D against a system-owned demo agent before hitting a non-dismissable 'Thanks for trying AURA' modal. Backed by guest JWTs, a per-guest/per-IP rate limiter behind a `Clock` trait, hardcoded cheap server-side defaults, and an `AURA_PUBLIC_GENERATION_ENABLED` kill-switch for the expensive endpoints. (`ad6ec51`, `365f7ad`, `4119f4c`, `205799e`)
- Ported the aura-website Product, Changelog, Feedback, and Pricing pages into a new `MarketingShell` mounted on logged-out routes, and reworked the logged-out chat empty state into an inline `ComposePanel` with five example prompts, a `LoginOverlay` modal over the shell, a Logout entry in the File menu, and a titlebar layout that now keeps native window controls reachable. (`85803f2`, `3c6e166`, `1701e37`, `486031d`, `b91ef5e`, `95e9ae0`, `a22bf58`)
- Finished the cross-agent `send_to_agent` fix: the server now posts agent B's reply back into agent A's session as a follow-up turn with depth-guarded, UTF-8-safe fire-and-forget delivery; the WebSocket wire shape is locked and documented; the receiving panel's history matcher and global cache invalidator live-update without a refresh; and a new `from_agent_id` field drives a '↩ from <agent>' badge so cross-agent messages stop looking like duplicate user prompts. (`1d01f6e`, `6d4b706`, `8375288`, `0700ed0`, `ae3f226`, `1843f16`, `6ed9c02`, `2cc749a`)
- Generation streams no longer trip the 30s 'Agent paused' watchdog on long renders: handlers emit a synthetic `generation_start` as the very first SSE frame, send a 15s heartbeat while the upstream router is silent, and the on-bubble image ETA was retuned twice — first to a stable monotonic latch, then to a simple linear countdown from a per-model baseline (with `gpt-image-2` bumped to 120s) so the digits stop snapping to 'Almost done...'. (`e5e4453`, `6508b66`, `1bab437`, `5bcdc53`, `913e0b7`, `ad63662`, `b3ba353`)
- Logged-out polish: session delete (X) is now a real sibling button (no more nested-interactive HTML) and hops to the next remaining session instead of spawning a fresh empty chat, mode-pill clicks keep the textarea focused, the login form auto-focuses and selects the email field on entry, and visiting the login modal no longer mints an empty 'New chat' row on every round-trip. (`9c39da8`, `609f802`, `9c4fef5`, `a6c7f57`)
- Auth now rehosts zOS Matrix `mxc://` profile pictures into Aura's S3 bucket on first sync (one-time per user, never overwriting Aura-uploaded avatars) so frontends get a permanent URL alongside the existing display-name sync. (`4a45437`)
- Small chat polish: the assistant bubble's copy button now sits left of the leading Block chevron instead of covering Thought/File/Spec headers, and the input bar's stray '·' divider is hidden on projectless chats where the orbit indicator renders nothing. (`3e5d3e3`)

## 4:38 PM — Windows release builds stop mixing rustc 1.94.1 and 1.95.0

Late-evening fix to the Windows half of the desktop release pipeline after a runner-image bump introduced a parallel rustc.

- Pinned `RUSTC`, `CARGO`, and `RUSTDOC` to the dtolnay-installed toolchain on Windows runners using `cygpath -w` so native PATH lookups honor it, stopping `sccache rustc` from falling through to the runner image's preinstalled rustc 1.95.0 and tripping E0514 against 1.94.1 rmeta files; shared-key suffixes were bumped to `*-v2` so the poisoned cache is not restored. (`7cd35a7`)
