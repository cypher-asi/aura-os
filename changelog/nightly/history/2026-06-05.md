# A new /code marketing page, Telegram fixes, and faster desktop CI

- Date: `2026-06-05`
- Channel: `nightly`
- Version: `0.1.0-nightly.620.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.620.1

Today's nightly is anchored by a substantial rebuild of the marketing site's /code and /agents first screens around a shared layout and a mock Projects desktop, alongside meaningful fixes to Telegram-linked agents and a large overhaul of the desktop release pipeline.

## 10:07 PM — /code page leads with a mock Projects desktop

The marketing /code page was restructured around an Agents-style centered hero with a full mock of the Projects workspace beneath it.

- Replaced the old product-screen sections on /code with a centered PageHero and a new MockProjectsWorkspace (explorer, agent status, task feed, terminal, sidekick) framed by the shared MockAuraApp chrome. (`6be27e0`)
- Gave the public blog archive a polish pass on layout and styles. (`8bc84fd`)

## 10:47 PM — Telegram-linked agents stop failing with empty model errors

External Telegram turns now pin a model and surface real agent errors instead of a generic apology.

- Picker-less Telegram turns now pin the latest frontier model at medium reasoning effort so agents without a default_model no longer fail the harness turn with "model name must not be empty". (`55cb5f9`)
- Added a ChannelError::Agent variant so agent-reported errors are threaded back into the chat, and the bridge now greets users with the agent's real name via "Connected to <name>". (`55cb5f9`)

## 10:49 PM — Shared first-screen layout for /code and /agents, plus a Telegram IDOR fix

Marketing's two main pages were unified around a shared MarketingFirstScreen, the /code mock desktop was made visible and sized correctly, and desktop Telegram links were routed to the prod control plane with an ownership check.

- Extracted a shared MarketingFirstScreen so /code and /agents use the same centered hero band and stage start position, with the /agents orb video and AgentMarquee now anchored to the bottom of the first screen. (`7b1ced2`, `b5d3525`)
- Made the /code mock desktop actually render and dominate the first screen by giving its container a definite height so cqh resolves, enlarging the frame to ~96% of the stage, and tuning its start position and size. (`90e8d1e`, `08d93d0`, `ebcac06`)
- Updated the /code hero copy to "Ship software while you sleep." positioning AURA as an open-source frontier coding harness. (`9266f8f`)
- Routed desktop Telegram link/list/disconnect calls to the prod control-plane (api.aura.ai) so Connect no longer 503s on the bundled local server, and closed an IDOR by scoping list_channels and disconnect_channel to the caller's JWT and verifying link ownership. (`3a3b927`)
- Introduced a dedicated --color-accent-text token, brightened to #a855f7 in dark purple mode, so accent text is readable while fills, chips, and borders are unchanged across dozens of components. (`68a3147`)

## 11:33 PM — /agents orb video polish and a working blog in dev

The /agents orb video got a symmetric, tighter fade and a full-bleed treatment, while local dev builds now pull real blog posts from the prod API.

- Reworked the /agents orb video so its top and bottom fades are symmetric, tightened the visible band to 48%-52%, and let the stage extend edge-to-edge with the AgentMarquee while keeping the hero text in its gutter. (`2101b43`, `28a9da8`, `08db223`, `bd9dfd6`, `a25dd79`)
- Dev /blog now always fetches from the prod blog origin via resolveBlogApiUrl so local builds show real posts instead of the empty-state placeholder, while prod and native builds keep same-origin behavior. (`ce8be53`, `2c3b0fe`)

## 9:41 AM — Faster, more resilient desktop release pipeline

A large pass on the release workflows added retries around Node setup, new validation and timing tooling, and reshaped the nightly and stable desktop release pipelines.

- Hardened the shared setup-node action with up to three retries plus a post-install version verification, keeping the Windows-only registry reachability gate but ensuring transient TLS or manifest failures no longer leave runners on the wrong Node version. (`776f003`)
- Substantially restructured the nightly and stable desktop release workflows and added new CI tooling for performance benchmarking, release preflight, artifact validation, packager-config patching, and run timing summaries. (`776f003`)
