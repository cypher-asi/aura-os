# Preview and Design modes land in the in-app browser

- Date: `2026-08-10`
- Channel: `nightly`
- Version: `0.1.0-nightly.784.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.784.1

Today's nightly is a single, substantial change: the browser panel gains dedicated Preview and Design modes, backed by a new CDP-driven element inspector that streams inspection results end-to-end from the Rust backend into the UI. Both shipped server channels now enable the Chromium/CDP backend by default so this works in web-server builds as well as the desktop packages for Linux, macOS, and Windows.

## 3:28 AM — Preview and Design modes for the in-app browser

The browser panel now offers explicit Preview and Design modes, including a design toolbar, an element inspector, and a full CDP inspection pipeline from Chromium through the server into the UI.

- Added Preview and Design modes to the browser panel, with a new BrowserDesignToolbar and BrowserDesignInspector plus shared design-mode and design-context modules driving how the viewport, tabs, and browser instance behave in each mode. (`fe5f7b0`)
- Implemented a CDP-backed element inspector: a new inspect module and Inspect client message flow inspection requests through the browser session loop and stream InspectionResult events over the WebSocket handler as 'inspection' payloads to the interface. (`fe5f7b0`)
- Enabled the Chromium/CDP browser backend by default on both dev-channel and stable-channel server builds so Preview and Design work in web-server deployments as well as the desktop package, while feature-minimal builds can still fall back to the stub backend. (`fe5f7b0`)
- Extended the agent chat panel, browser API client, and browser-panel store to carry design-mode context, and expanded CDP smoke tests and browser viewport tests to cover the new inspection and mode-switching behavior. (`fe5f7b0`)

## Highlights

- New Preview and Design modes in the browser panel
- CDP-backed element inspector wired through server and UI
- Chromium/CDP backend enabled on both dev and stable channels
