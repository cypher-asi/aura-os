# Faster file navigation in the explorer and IDE

- Date: `2026-09-01`
- Channel: `nightly`
- Version: `0.1.0-nightly.826.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.826.1

Today's nightly focuses on making the file browsing experience feel more at home inside Aura: the File Explorer gains bulk expand and collapse controls, and opening a file preview in the IDE now remembers where you came from so you can jump straight back.

## 7:59 AM — Expand/collapse controls and return navigation for file previews

The File Explorer picks up bulk folder controls, and opening a file into the IDE now preserves a way back to the originating panel.

- Added dedicated Expand all folders and Collapse all folders buttons to the File Explorer header, with disabled states when no further action is possible, plus a rotating chevron for expanded folders on the mobile file list. (`c5d5312`)
- Opening a remote file from the Sidekick Files tab now navigates into the IDE while capturing the source route (including panel and hash state) as a returnTo target, so users can get back to exactly where they were browsing. (`e397f41`)
- Reordered the Sidekick taskbar so Files sits alongside Preview and Plans instead of being buried near the end, making the new file preview flow easier to reach. (`e397f41`)

## Highlights

- Expand and collapse all folders in the File Explorer
- File previews now offer a return path back to their source view
