# Self-improving agents land with a new Learning tab

- Date: `2026-06-27`
- Channel: `nightly`
- Version: `0.1.0-nightly.712.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.712.1

Today's nightly is anchored by a single substantial change: Aura agents can now propose improvements to themselves. A new server-side workflow, harness-proxy plumbing, and a dedicated Learning tab in the agent panel turn self-improvement into a first-class, reviewable feature across the stack.

## 1:58 AM — Self-improving agent proposal workflow

A new end-to-end workflow lets agents generate improvement proposals, surfaces them in a dedicated Learning tab, and exposes self-improvement as a tool inside chat sessions.

- Introduced a server-side self-improvement subsystem with a new handler module, agent service, router endpoints, and harness-proxy integration so agents can produce and manage improvement proposals. (`adeb283`)
- Added a Learning tab to the Agent Info panel, backed by a new agent-improvements API client and shared entity types, giving users a place to review what an agent has proposed about itself. (`adeb283`)
- Wired a self-improvement tool into both agent and instance chat sessions, gated by each agent's self-improvement mode and resolved via a new template_agent_id passed through the installed-tools context. (`adeb283`)
- Expanded the harness-proxy local create/update/manage paths and added dedicated integration tests for self-improvement and skills updates to lock in the new behavior. (`adeb283`)

## Highlights

- Agents can now propose self-improvements
- New Learning tab in the Agent Info panel
- Self-improvement tool wired into agent and instance chat sessions
