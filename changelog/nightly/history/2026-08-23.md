# Faster prompting, hands-free input, and conversation branching

- Date: `2026-08-23`
- Channel: `nightly`
- Version: `0.1.0-nightly.799.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.799.1

A focused nightly for the chat surface: a new global quick prompt palette, voice dictation in the composer, and the ability to fork any assistant reply into a fresh conversation without disturbing the original.

## 4:00 AM — Quick prompt palette, voice dictation, and reply branching land in chat

Three composer- and shell-level features shipped together, expanding how users start, dictate, and fork conversations.

- A new Quick Prompt palette is wired into the Aura shell and menu bar, letting users draft a prompt from anywhere and hand it off to the active agent's composer via a shared quick-prompt store that merges into the existing draft. (`da686ae`)
- Chat composer gains built-in voice dictation on both desktop and mobile, with a dedicated inline action slot in the input bar that reflows padding around the send/stop button so the mic never overlaps existing controls. (`914e247`)
- Any completed assistant reply can now be branched into a brand-new session: the server copies events through the selected message end into a fresh active session (leaving the original untouched) and the message actions menu exposes the new fork control. (`e01a708`)

## Highlights

- Global quick prompt palette from the menu bar
- Voice dictation built into the chat composer
- Branch any assistant reply into a new session
