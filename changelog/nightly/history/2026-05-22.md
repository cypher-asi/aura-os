# Public funnel analytics for logged-out chat

- Date: `2026-05-22`
- Channel: `nightly`
- Version: `0.1.0-nightly.550.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.550.1

A focused nightly that instruments the logged-out experience. Aura can now cleanly separate authenticated and anonymous usage in Mixpanel and follow the public visitor journey from first message through the login gate.

## 2:11 AM — Public visitor funnel and auth-state tagging in Mixpanel

Analytics now distinguish authenticated vs. public traffic and capture the key conversion steps in the logged-out shell.

- Every Mixpanel event carries a new is_authenticated super property, registered as false at init, flipped to true on identify, and reset on sign-out so authenticated and public metrics can be sliced independently. (`8e2db7e`)
- Instrumented the public funnel end-to-end with public_session_started when an anonymous session is provisioned and public_message_sent (tagged with the selected agent mode) when a visitor sends their first messages. (`8e2db7e`)
- The Keep Chatting gate and logged-out titlebar now emit public_gate_shown, public_login_clicked, and public_signup_clicked (with a source tag for titlebar entries), making it possible to measure gate-to-signup conversion. (`8e2db7e`)

## Highlights

- is_authenticated super property on every Mixpanel event
- New public funnel: session, message, gate, login, signup
