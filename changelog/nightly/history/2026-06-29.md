# Agent profile cards stop clipping long names

- Date: `2026-06-29`
- Channel: `nightly`
- Version: `0.1.0-nightly.713.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.713.1

A small but visible polish day for the Agents app: the 3D profile card nameplate was reflowed so long agent names no longer collide with the role tag. Desktop builds shipped for Linux, macOS (Intel and Apple Silicon), and Windows.

## 8:12 AM — Agent nameplate reflows name and role onto separate lines

The 3D agent profile card now stacks the role label below the name instead of floating it as a right-aligned pill, fixing overlap on longer agent names.

- Long agent names no longer collide with the role tag on the 3D profile card: the name now sits on its own top line, with a smaller left-aligned role pill rendered directly underneath it within the nameplate strip. (`c8a6f9b`)
- Nameplate typography was retuned to fit the new two-line layout, with the name dropping from 123px to 104px and the role pill shrinking (60px → 48px text, 103px → 72px pill height) so both elements sit comfortably on the plate. (`c8a6f9b`)

## Highlights

- Agent profile card nameplate redesigned to prevent role/name overlap
- Nightly desktop builds shipped for Linux, macOS, and Windows
