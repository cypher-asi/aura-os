## 12:13 AM — Streaming tail follows live thinking without hijacking scroll

The chat message list now auto-follows the model's live thinking output as it grows, while respecting an explicit scroll-up as intent to stay put.

- Chat auto-scrolls to the latest streamed reasoning as new thinking text lands, so long responses no longer drift below the fold while the model is still working. (`3c1f97d`)
- Scrolling upward during a live response is now treated as read-back intent — the tail stops pulling you back down until you re-engage with the latest output. (`3c1f97d`)
- The StreamingTail component gained direct access to the scroll container and auto-follow state, backed by new tests covering pinning, upward-scroll intent, and reading mode. (`3c1f97d`)
