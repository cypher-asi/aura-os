# A "+ new chat" overhaul: instant fresh canvas, live titles, and durable sessions

- Date: `2026-05-07`
- Channel: `nightly`
- Version: `0.1.0-nightly.474.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.474.1

Today's nightly is almost entirely about making the Chats sidekick feel right. The team rebuilt the "+ new chat" flow end to end — from the orphan "New chat" rows that did nothing on click, through the messy session-switch remounts, to a brand-new ChatGPT-style title generator that streams a real session label into the sidekick before the assistant even finishes its first reply. Along the way, agent personality finally reaches chat turns, and a long tail of binding, focus, and bubble-remount glitches got cleaned up.

## 5:47 PM — Dead "New chat" rows and unstable session switches, fixed at the source

An evening of foundational fixes for the Chats sidekick: orphan sessions are filtered server-side, agents heal their org bindings, and clicking between sessions stops thrashing the chat panel.

- List endpoints now drop zero-event sessions via a fan-out `list_events?limit=1` probe with fail-open behavior, killing the unclickable "New chat" rows that came from orphaned or pre-lazy-`+` legacy sessions. (`c16c910`)
- Legacy agents with a missing `org_id` now self-heal by falling back to the caller's single org, so the very first chat turn no longer 424s with `chat_persist_unavailable`; multi-org callers stay ambiguous on purpose. (`6a7ded1`)
- Switching sessions in the agents shell no longer remounts the bottom chat input bar or unmounts the prior assistant bubble — callbacks and empty-array props are now stable per `streamKey`, and an id-alias map preserves the assistant's React key across the placeholder-to-persisted swap. (`8e0129c`, `81d8b6f`)
- Cross-session clicks now reset the shared stream slot at the resolver layer instead of inside the panel, fixing the "first click does nothing, second click works" report where a new session inherited the previous session's events. (`2c795b8`)
- Agent identity (name, role, personality, skills) is now composed into a preamble and prepended to the chat system prompt on both interactive routes, so edits in the PersonalityTab actually change how the agent talks. (`9a33549`)

## 8:56 PM — Rebuilding the "+" fresh-canvas flow

A focused push on the "+ new chat" experience: the lane clears properly, the sidekick gets an optimistic placeholder, and transcripts stop bleeding across sessions.

- Clicking "+" in the agents shell now reliably mounts a fresh-canvas panel instead of leaving a blank `lanePlaceholder` div, by teaching the shell-target resolver to distinguish a cold load from an explicit user-cleared session. (`c3aeb20`)
- `handleNewChat` now clears every destination history key and the standalone stream slot (gated on active streaming), and the sidekick gains an optimistic muted "New chat" row with proper deletion and summarize-call guards. (`fd7a552`)
- Transcript snapshots are now scoped by the active history key and the agent chat panel stays mounted for known sessions, so warm switches no longer rearm the cold-load path or inherit stale same-agent history. (`b1a41d8`, `d354bd2`, `d957b25`)
- Selected sidekick rows now share the neutral overlay tokens used by the agent list (no more accent-tinted highlight from an undefined token, no font-weight shift on selection), and the image-mode upload send gate was repaired. (`9480f8a`, `c826bd6`, `f118ae8`)

## 9:46 PM — Pivot to server-persisted sessions for new chats

After live-testing the optimistic placeholder, the team pivoted: "+" now resets only local state and lets the first sent message create the real sidekick row through the persisted session list.

- The "+" action no longer synthesizes a client-side placeholder row; instead, the first sent message creates the durable sidekick entry through the persisted session list, removing ~660 lines of optimistic-row plumbing. (`6c7012d`)
- Pending chat rows are now promoted as soon as the server assigns a session id, and early summary attempts retry with backoff, so first-turn sessions become clickable and titled without a fragile refresh race. (`186c9ae`)
- The project chat panel stays mounted across the post-`+` URL flip so the first send uses the stream that was armed to create a new persisted session, and reclicking the already-selected agent preserves its session. (`bbee79c`, `5a427a4`, `13c2c1b`)

## 10:30 PM — Session summaries stop refusing non-coding chats

The Haiku summarizer's prompt is now content-agnostic, ending the "I don't have any agent coding session to summarize" titles that were getting persisted on trivial chats.

- The session-summary system prompt no longer assumes every chat is an "agent coding session," so trivial or non-coding turns get a real title instead of refusal prose persisted as the row label. (`aa14044`)

## 10:42 PM — ChatGPT-style live titles and authoritative agent bindings

The night ends with the marquee feature: short, human-readable session titles generated on the first message and streamed into the sidekick over the WebSocket bus — plus a fix for agents whose chats were invisible because their bindings lived outside the active org.

- Brand-new sessions now get a 2–5 word title (e.g. "Heartburn During Water Fast") generated by a tokio-spawned Haiku call on the user's first prompt, persisted as `summary_of_previous_context`, and pushed live over the WS event bus so the sidekick row flips from "New chat" before the assistant finishes streaming. (`44738c8`, `0d2fe13`)
- An optimistic "New chat" row is now inserted into both agents-app and projects-app sidekicks the moment the first message is sent, and gets its synthetic id swapped for the real `session_id` on `SessionReady` — without racing the live title patch. (`a579da2`, `fff04e7`)
- Agent project bindings now come from `GET /api/agents/:agent_id/projects` rather than the active-org sidebar snapshot, so remote agents like Glenn and Machina that were auto-bound to a per-org Home project no longer render "No sessions yet" while real sessions sit in storage; a new pending lane prevents the fresh-canvas flicker. (`198f5f2`)
- Pressing "+" now drops the cursor straight into the chat input on desktop (mobile keeps no auto-focus to avoid keyboard pop-ups), and the prior assistant bubble stays aliased even when Send appends a new user message in the same render as the end-of-turn swap. (`e3fcec1`, `91c47d4`)
- Desktop chat-input attachment intake (paste, drag-drop, file picker) is now instrumented end-to-end with `[attach]`-prefixed logs, and `processImageFile`/`processTextFile` were hardened with `FileReader` error handlers so a synthetic clipboard file can't make `Promise.all` hang forever. (`95f0d0a`)

## Highlights

- Sidekick no longer shows orphan "New chat" rows that go nowhere
- ChatGPT-style session titles generated on first message and pushed live over WS
- Stable chat input bar and assistant bubble across session switches
- Agent personality, role, and skills now flow into chat turns
- Cross-org agent bindings (e.g. Glenn, Machina) now surface their real chats
