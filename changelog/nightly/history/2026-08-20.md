# Grok 4.6 lands and desktop gains a custom browser path

- Date: `2026-08-20`
- Channel: `nightly`
- Version: `0.1.0-nightly.795.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.795.1

Today's nightly brings xAI's Grok 4.6 into Aura's managed model catalog with full pricing and reasoning support, and gives desktop users control over which Chromium executable powers managed browsing.

## 9:52 AM — Grok 4.6 added to the managed model catalog

xAI's Grok 4.6 is now a first-class Aura-managed chat model with tiered pricing and the full reasoning effort ladder.

- Added Grok 4.6 as an Aura-managed model with a 500K context window, the full low/medium/high/xhigh reasoning ladder, a 'high' default effort, and a 1.44 credit multiplier. (`06999fb`)
- Wired exact xAI pricing for Grok 4.6 into both the runtime pricing table and the benchmark pricing script, including a cached-input rate of $0.50/MTok and a long-context step-up that kicks in at 200K input tokens. (`06999fb`)
- Normalized aliases like aura-grok-4-6 and xai/grok-4.6 so persisted sessions and raw provider ids resolve cleanly onto the new model. (`06999fb`)

## 7:59 AM — Configurable Chromium executable for managed browsers on Desktop

Desktop users can now point Aura's managed browser at a specific Chromium binary, with the choice persisted across launches and surfaced in Advanced settings.

- Introduced persisted browser runtime settings so a user-chosen Chromium executable path is loaded from disk at startup and merged with environment-based CDP configuration, with the executable and its source logged during backend initialization. (`a1cd3b1`)
- Added a new /api/browser-executable endpoint on the desktop app to read and update the managed browser path, including validation that returns a 400 on bad input and reports the resolved status back to the UI. (`a1cd3b1`)
- Built out the Advanced section of Settings with UI for viewing and changing the managed browser executable, backed by new desktop API bindings and tests. (`a1cd3b1`)
- Broadened Chromium error handling so both launch and configuration failures map to a clear 503 response, making misconfigured executables easier to diagnose. (`a1cd3b1`)

## Highlights

- Grok 4.6 available with 500K context and xhigh reasoning
- Configure a custom Chromium executable for managed browsers
- New Advanced settings surface for browser executable path
