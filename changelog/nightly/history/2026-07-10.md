# Agent continuity, GPT-5.6 models, and a safer macOS relaunch

- Date: `2026-07-10`
- Channel: `nightly`
- Version: `0.1.0-nightly.757.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.757.1

A feature-heavy nightly: agents gain continuity controls and retrieval evidence in the UI, the model catalog picks up the GPT-5.6 family with a new XHigh reasoning tier, macOS updates now relaunch cleanly after shutdown, and cloud tool callbacks correctly resolve org identity.

## 4:26 AM — Cloud tool callbacks resolve org identity correctly

Direct cloud callbacks that only carry a zOS JWT now look up the Aura Network user before checking org membership, so tool actions like web search stop being rejected for authorized owners.

- Server-side role checks now fetch the current Aura Network user when the JWT identity doesn't match an org member, cache the resolved network user ID and profile on the validation session, and rely on that identity for subsequent tool callbacks — with regression coverage via a new end-to-end web-search test. (`c394e57`)

## 6:39 AM — macOS updater waits for shutdown before relaunching

The desktop updater no longer races LaunchServices on macOS; a small handoff process waits for Aura to fully exit before reopening the freshly installed bundle.

- Replaced the immediate `open -n` relaunch with a shell handoff that polls the parent PID (up to a 30-second ceiling) and only then execs `/usr/bin/open` on the new bundle, applied to both standard updates and the /Applications relocation path. (`c8307f1`)
- Relaunch telemetry now records the handoff PID alongside the bundle path, making post-update failures easier to trace in the updater log. (`c8307f1`)

## 7:06 AM — GPT-5.6 family added with a new XHigh reasoning tier

The model catalog gains three GPT-5.6 variants and the reasoning-effort superset grows a distinct XHigh tier between High and Max.

- Added GPT-5.6 Sol, Terra, and Luna to the model catalog and benchmark pricing tables, each with input/output and cache-read/write rates. (`f0aebe9`)
- Introduced a first-class `XHigh` reasoning effort in the aura-protocol enum and TypeScript bindings; the wire format now round-trips `xhigh` as its own tier instead of folding into `high`, and documentation was updated to describe the provider-neutral superset. (`f0aebe9`)

## 2:54 PM — Agent Continuity controls and memory retrieval evidence

The Agents panel's Memory tab now exposes continuity configuration and shows what the agent actually retrieved, backed by new proxy routes and browser-tested flows.

- New continuity configuration and latest-retrieval endpoints on the harness proxy (`/memory/continuity` GET/PUT and `/memory/retrieval/latest`) let the UI read and update per-agent continuity settings and inspect the most recent retrieval trace. (`fb16613`)
- The Memory tab and preview gained continuity controls, approval and correction actions, and retrieval-evidence rendering, with supporting analytics events and a typed memory API client. (`fb16613`)
- Added a Playwright end-to-end spec for the agent-continuity flow plus an authenticated-app mock helper, giving the new controls browser-level coverage. (`fb16613`)

## Highlights

- Agent Continuity controls and retrieval evidence in the Memory tab
- GPT-5.6 Sol, Terra, and Luna added with a new XHigh reasoning tier
- macOS updater defers relaunch until shutdown completes
- Cloud tool callbacks correctly resolve Aura Network identity
