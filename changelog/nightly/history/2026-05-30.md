# Self-healing public chat, model effort controls, and steadier CI

- Date: `2026-05-30`
- Channel: `nightly`
- Version: `0.1.0-nightly.570.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.570.1

Today's nightly tightens a stack of chat and marketing surfaces, ships per-model reasoning effort in the picker, fixes a long-standing dev-run agent pileup in the Rust core, and hardens release pipelines against transient runner DNS hiccups.

## 9:27 PM — Public chat self-heals, model picker gains effort controls

A dense late-evening batch reshaped the chat input, recovered public chat from stale guest tokens, and polished several marketing and layout surfaces.

- Public chat now silently recovers from server-side guest-token secret rotations: a new isGuestAuthError predicate detects 401s, drops the stale cached token, re-mints a fresh one, and transparently retries the turn across PublicChatView, MobilePublicChatView, and the dispatch-media boundary. (`72f8ed3`)
- The model picker now shows a credit-multiplier badge per chat model and a hover flyout to pick a reasoning effort (Low/Medium/High/XHigh/Max); the selection is persisted per model and forwarded as reasoning_effort on the chat stream request from both desktop and mobile input bars. (`b135e7a`)
- The /product page's agent section replaces empty PhoneShell placeholders with three looping mobile chat mockups, each showing a visitor texting a different AURA agent using the landing hero's typewriter and streamed tool-card primitives. (`4f9d48d`)
- Project task checkmarks now update live during dev runs — useProjectLayoutData subscribes to task_updated edges so the Tasks tab reflects completed work even when the user is watching the Run tab, no manual refresh required. (`567338e`)
- Smaller layout polish across chat and marketing: the public-chat transcript now fills full height and scrolls under the floating input bar, the public sidebar nav slides between center and bottom on side-area toggle, the marketing product hero video fades cleanly into the page, and the overlay scrollbar thumb is now a properly rounded pill that widens on hover and drag. (`91af433`, `5ad826b`, `05a3554`, `0a51c5b`)

## 10:32 PM — Ephemeral executor agents stop piling up in the projects sidebar

A Core Rust fix prevents ad-hoc dev/automation runs from leaving permanent duplicate Executor rows in the projects sidebar.

- System-minted Loop/Executor instance IDs are now tracked in a storage-independent SettingsStore ledger, so the janitor can reclaim ephemeral executor rows and the sidebar can hide them even when aura-storage strips the instance_role/source columns and they come back masquerading as plain Chat rows. (`c895064`)

## 10:32 AM — Media generation feels alive, generated images land cleanly

Two morning changes made image generation in chat feel less janky end-to-end, from the loading placeholder to the final reveal.

- The image/video generation placeholder swaps its static CSS dot grid for a canvas where dots pulse in radius and brightness in flowing ripple waves, so the wait reads as actively working; prefers-reduced-motion still renders a single static frame. (`c5b5017`)
- Generated chat images no longer paint in progressively or grow the frame downward as the bitmap arrives: a new GeneratedImageFrame reserves a square box with a loader and FadeInImage now gates its reveal on img.decode(), so the picture appears in one fully-decoded fade. (`64a35d8`)

## 11:05 AM — setup-node hardened against self-hosted runner DNS blips

Release Infrastructure wraps setup-node in a reachability gate to absorb transient DNS failures, with a quick follow-up to keep subdirectory-checkout jobs working.

- A new local ./.github/actions/setup-node composite polls api.github.com and nodejs.org with backoff before installing Node, so a transient 'getaddrinfo ENOTFOUND' on the self-hosted runners no longer kills the build-sidecar job on the first attempt; all first-party workflows now share this wrapper and a centrally pinned Node version. (`4e4d177`)
- Five publish-manifest and changelog jobs that check the repo out into subdirectories — where the local composite action can't be resolved — were reverted to upstream actions/setup-node@v5; those run on GitHub-hosted runners that never had the DNS issue in the first place. (`36fc5ac`)
