# AURA Council, live subagent threads, and shareable chats

- Date: `2026-06-01`
- Channel: `nightly`
- Version: `0.1.0-nightly.578.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.578.1

A heavy day centered on multi-agent chat: live subagent threads grew from a clickable card into a fully promptable, persisted slide-over, AURA Council landed end-to-end with N model fan-out and a synthesizer, and assistant messages picked up a Copy/Share/Reload action row backed by a new public share link. Smaller but meaningful work tightened the Sidekick Run pane, added a forced-upgrade gate for stale desktop builds, fixed long-standing sys-admin auth gaps, and shipped an in-app screen-recorded demo command on Desktop.
