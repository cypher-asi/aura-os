# Chat Recall: search your past sessions from the sidebar

- Date: `2026-08-04`
- Channel: `nightly`
- Version: `0.1.0-nightly.782.1`
- Release: https://github.com/cypher-asi/aura-os/releases/tag/v0.1.0-nightly.782.1

Today's nightly introduces Recall, a read-only way to search across your completed chat sessions and jump back to the original message. The feature ships end-to-end across the desktop chat UI, a typed API client, and a new server-side search handler with strict safety and latency guardrails.

## 12:59 AM — Evidence-backed chat Recall across past sessions

A new Recall workflow lets users search their completed chat history from the chat sidebar and open the source session, backed by a safety-focused read-only server endpoint.

- Added a Recall entry point to the chat left panel and a dedicated Recall modal for querying past sessions and navigating to the original message, rather than injecting recalled text into the current chat. (`04bb0a1`)
- Introduced a typed history search client in the shared agents API so the desktop app can call Recall with a consistent, tested contract. (`04bb0a1`)
- Shipped a new server handler that scans up to 50 recent sessions with per-session (4s) and overall (12s) deadlines, capped query length, and bounded plain-text snippets — and reports scanned vs. skipped counts so partial searches are never presented as complete. (`04bb0a1`)
- Hardened test fixtures to avoid leaking credential-like data into test logs, keeping Recall's read-only, no-secrets posture visible in CI as well. (`04bb0a1`)

## Highlights

- New Recall modal in the chat sidebar for searching past sessions
- Bounded, evidence-only server search with per-read and overall deadlines
- Partial-result honesty: UI surfaces scanned and skipped session counts
